# Анатомия сотовой связи

Интерактивный 3D-атлас (Three.js) о том, как работает сотовая связь:

- **Путь сигнала** — от микрофона абонента A через эфир, базовую станцию, транспорт и ядро сети до абонента B (7 шагов).
- **Анатомия вышки** — разборная модель макросоты: антенны, RRU, РРЛ, GNSS, BBU, питание, заземление.
- **Анатомия смартфона** — антенны в рамке, модем, RF-фронтенд, SIM.
- **Физика** — созвездие QAM, поднесущие OFDM, калькулятор затухания в свободном пространстве.
- **Соты и хендовер** — живая симуляция RSRP и события A3.
- **Анатомия спутника** — LEO-аппарат, фазированная решётка, лазерные каналы, орбиты LEO/MEO/GEO.
- **Почему возможен перехват** — ложная базовая станция, понижение до 2G, SS7, законный перехват и меры защиты.

Один файл `index.html`, без сборки. Откройте его через любой статический сервер:

```bash
python3 -m http.server 8000
```

и перейдите на http://localhost:8000. Нужен интернет: Three.js и шрифты грузятся с CDN.
